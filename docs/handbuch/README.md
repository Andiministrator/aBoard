# aBoard-Handbuch

[English](../handbook/README.md) · **Deutsch**

Dieses Handbuch beschreibt, wie man aBoard einsetzt und daran mitarbeitet. Vorwissen ist nicht nötig.

> **Was in diesem Repository liegt:** die Board-App als einzelne HTML-Datei, in zwei Fassungen, und der optionale Mehrbenutzer-Server (Go, unter `server/`). Die Werkzeuge für die Zusammenarbeit mit Claude Code sind nicht veröffentlicht.

## Wo anfangen?

| Du willst … | Lies zuerst |
|---|---|
| wissen, welche Fassung zu dir passt | [Varianten](varianten.md) |
| aBoard einrichten oder aktualisieren | [Installation](installation.md) |
| mit dem Board arbeiten | [Bedienung](bedienung.md) |
| am Code von aBoard mitarbeiten | [Entwicklung](entwicklung.md) |
| einen Server für ein Team betreiben | [Server: Container](server/container.md) |

## Alle Kapitel

- [Varianten](varianten.md): die beiden Fassungen im Vergleich, wo die Daten liegen, Ordner-Verbindung
- [Installation](installation.md): beschaffen, einrichten, aktualisieren
- [Bedienung](bedienung.md): Spalten, Karten, Swimlanes, Filter, Tastatur, Kalender
- [Entwicklung](entwicklung.md): bauen, testen, Aufbau des Codes

## Server (Mehrbenutzer-Betrieb)

- [Container](server/container.md): Server bauen und starten
- [Konfiguration](server/konfiguration.md): Umgebungsvariablen und Einstellungen
- [Anmeldung](server/anmeldung.md): Passwort, zweiter Faktor, Anmeldung über einen Identitätsanbieter
- [Administration](server/administration.md): Nutzer, Boards, Sicherungen, Betrieb
- [API](server/api.md): REST-Schnittstelle
