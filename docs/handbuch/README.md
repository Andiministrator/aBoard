# aBoard-Handbuch

[English](../handbook/README.md) · **Deutsch**

Dieses Handbuch beschreibt, wie man aBoard einsetzt und daran mitarbeitet. Vorwissen ist nicht nötig.

> **Was in diesem Repository liegt:** die Board-App als einzelne HTML-Datei, in zwei Fassungen. Der Mehrbenutzer-Server und die Werkzeuge für die Zusammenarbeit mit Claude Code sind noch nicht veröffentlicht. Wo das Handbuch den Server erwähnt, beschreibt es Funktionen, die erst mit ihm zur Verfügung stehen.

## Wo anfangen?

| Du willst … | Lies zuerst |
|---|---|
| wissen, welche Fassung zu dir passt | [Varianten](varianten.md) |
| aBoard einrichten oder aktualisieren | [Installation](installation.md) |
| mit dem Board arbeiten | [Bedienung](bedienung.md) |
| am Code von aBoard mitarbeiten | [Entwicklung](entwicklung.md) |

## Alle Kapitel

- [Varianten](varianten.md): die beiden Fassungen im Vergleich, wo die Daten liegen, Ordner-Verbindung
- [Installation](installation.md): beschaffen, einrichten, aktualisieren
- [Bedienung](bedienung.md): Spalten, Karten, Swimlanes, Filter, Tastatur, Kalender
- [Entwicklung](entwicklung.md): bauen, testen, Aufbau des Codes
