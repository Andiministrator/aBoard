# aBoard Handbook

**English** · [Deutsch](../handbuch/README.md)

This handbook describes how to use aBoard and how to contribute to it. No prior knowledge is required. The documentation is available in English and German.

> **What is in this repository:** the board app as a single HTML file, in two versions, and the optional multi-user server (Go, under `server/`). The tools for working together with Claude Code are not published.
