# aBoard Handbook

**English** · [Deutsch](../handbuch/README.md)

This handbook describes how to use aBoard and how to contribute to it. No prior knowledge is required. The documentation is available in English and German.

> **What is in this repository:** the board app as a single HTML file, in two versions. The multi-user server and the tools for working together with Claude Code have not been published yet. Where the handbook mentions the server, it describes features that only become available with it.
